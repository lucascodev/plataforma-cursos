# Código de conduta

Este projeto é um espaço de estudo. Queremos que qualquer pessoa, em qualquer nível, se sinta à vontade para perguntar, errar e contribuir.

## O que esperamos

- Tratar todo mundo com respeito, inclusive quando discordar.
- Criticar ideias e código, nunca pessoas.
- Explicar com paciência; quem pergunta o básico está fazendo exatamente o que deve.
- Dar crédito ao trabalho dos outros.

## O que não aceitamos

- Assédio, ofensas, discriminação ou ataques pessoais, em público ou em particular.
- Expor dados pessoais de alguém sem permissão.
- Insistir em contato depois de a pessoa pedir para parar.

## Como relatar

Relate pelo relato privado do GitHub (aba **Security**) ou por mensagem direta a quem mantém o projeto. Os relatos são tratados com sigilo. Quem descumprir este código pode receber um aviso ou ser bloqueado no repositório.
